# 🏦 SmartBank - Digital Queue Management System

SmartBank is a modern, responsive digital queue management system designed to optimize customer flow, minimize branch waiting times, and streamline teller counter operations in banking environments.

---

## 📌 Project Summary

Traditional bank branch queues often result in long wait times, crowded lobbies, and inefficient teller allocation. **SmartBank** provides a digital queueing platform where customers can authenticate, take digital service tickets, monitor their position in real-time, and get served seamlessly by counter staff.

### Key Objectives:
* **Reduce Lobby Congestion**: Enable digital queue numbers and live status tracking.
* **Role-Based Workflow**: Dedicated interfaces for **Customers**, **Staff/Tellers**, and **Branch Administrators**.
* **Streamline Operations**: Empower tellers to call, serve, hold, and complete tickets efficiently.
* **Real-Time Visibility**: Provide administrative analytics on customer wait times and counter performance.

---

## 🚀 Key Features

* 🔐 **Authentication & Registration**: Secure access for customers, staff, and administrators.
* 🎫 **Customer Queueing**: Digital ticket issuance with service category selection (Cash Deposits, Withdrawals, Loans, Customer Support).
* 👨‍💼 **Teller / Staff Counter**: Dashboard to call next in line, serve tickets, and manage counter status.
* 📊 **Admin Analytics**: High-level overview of daily transactions, average wait times, active counters, and queue velocity.
* 📱 **Responsive Design**: Clean, accessible UI optimized for desktops, tablets, and mobile devices.

---

## 🛠️ Tech Stack

* **Frontend**: HTML5, CSS3 (Modern Custom Properties & Flexbox/Grid Layouts), Vanilla JavaScript (ES6+)
* **Backend**: REST API service for authentication and queue management
