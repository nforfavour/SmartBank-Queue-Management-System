# SmartBank 🏦

A modern digital queue management system designed for banking environments. Streamlines customer queues, teller service counters, and branch administration.

## ✨ Features
- **Customer Portal**: Digital ticket generation, real-time queue tracking, service category selection.
- **Staff / Teller Counter**: Call next customer, serve, hold, and complete tickets with minimal latency.
- **Admin Dashboard**: Branch analytics, counter efficiency, average wait times, and queue management.
- **Role-Based Access Control**: Secure customer, staff, and admin navigation.

## 🚀 Getting Started

### Prerequisites
- Modern web browser
- (Optional) Live Server extension in VS Code

### Running the Frontend
1. Open `frontend/index.html` in your browser, or right-click `frontend/index.html` in VS Code and select **Open with Live Server**.
2. Log in or create a new account to experience the queue system.
